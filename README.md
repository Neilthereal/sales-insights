# sales-insights

Ecommerce sales data analysis toolkit: load an orders dataset, compute core
business metrics (GMV, AOV, trends, category mix, top products, repeat rate,
regional split), and generate a Markdown report with ASCII charts and
auto-written key findings. Python 3.10+, standard library only.

## Quick start

```bash
python3 run.py --regen      # generate the demo dataset (deterministic seed)
python3 run.py              # analyze datasets/orders.csv -> report.md
python3 -m unittest discover -s tests   # 7 tests
```

## What it does

- **Totals**: GMV, order count, AOV, unique customers, repeat-purchase rate
- **Trend**: monthly GMV with month-over-month growth + ASCII bar chart
- **Mix**: category revenue share, top-8 products by GMV, regional split
- **Findings**: auto-generated insights (top category, best month, repeat-rate
  read, regional concentration)

## Sample output

```
GMV 1,405,461 元 | 订单 3,600 | AOV 390.41 元 | 复购率 63.7%
品类占比: Electronics 51% / Apparel 24% / Sports 10% / Home 9% / Beauty 6%
发现: Electronics 是第一大品类，贡献 51.3% 的 GMV。
```

## Project structure

```
insights/
  data_gen.py  # deterministic synthetic dataset generator (seeded RNG)
  analyze.py   # metrics computation
  report.py    # Markdown report + ASCII charts
datasets/
  orders.csv   # generated demo data (3,600 orders, 2026-01..2026-09)
tests/         # 7 unit tests (stdlib unittest)
run.py         # CLI
```

## Data

The bundled dataset is **synthetic** -- generated by `insights/data_gen.py`
with a fixed seed so the demo is reproducible offline. It is realistic in
shape (seasonality, category mix, repeat buyers) but every number is made up.
Point `run.py --dataset` at a real export (same CSV columns) to analyze real
data: `order_id,order_date,customer_id,region,category,product_name,quantity,unit_price`.

## Limitations

Synthetic demo data only; no cohort/LTV analysis, no statistical testing of
trend changes, single-currency. Natural extensions: RFM segmentation, cohort
retention curves, anomaly detection on daily GMV.
